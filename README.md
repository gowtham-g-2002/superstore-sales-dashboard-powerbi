# Super Store Sales Dashboard 📊

An end-to-end Power BI dashboard built on the SuperStore Sales dataset, 
covering sales performance, profitability, and a 15-day sales forecast.

## Overview
This project analyzes **$1.57M** in sales across regions, segments, and 
categories, surfacing key business insights through interactive visuals 
and slicers (Central, East, South, West).

## Key Features
- **KPI Summary**: Total Sales, Quantity Sold, Profit, and Average Delivery Days
- **Sales by Payment Mode**: COD, Online, and Card transaction breakdown
- **Regional & Segment Analysis**: Sales by Region, Segment (Consumer/Corporate/Home Office)
- **Time Series Trends**: Monthly Sales YoY and Profit by Order Date
- **Shipping & Category Insights**: Sales by Ship Mode and Product Category/Sub-Category
- **Geo Visualization**: Sum of Sales and Profit plotted by U.S. State
- **15-Day Sales Forecast**: Trend-based forecasting to project near-term sales
- **State-wise Sales Ranking**: Top-performing states (California, New York, Texas, etc.)

## Tools Used
- Power BI (DAX, Power Query)
- Power BI built-in forecasting

## Dataset
SuperStore Sales Dataset (Order-level transactional data: Sales, Profit, 
Quantity, Region, Category, Ship Mode, Payment Mode)

## Files
- `Sales_Dashboard.pbix` — Power BI dashboard file
- `SuperStore_Sales_Dataset.csv` — source dataset
- Dashboard screenshots (`.png`)

## Insights
- Office Supplies leads category-wise sales (0.64M), followed by Technology (0.47M) and Furniture (0.45M)
- Standard Class shipping accounts for the majority of sales (0.33M)
- California, New York, and Texas are the top 3 revenue-generating states
